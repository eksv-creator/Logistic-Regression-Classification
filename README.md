# Бинарная классификация методом логистической регрессии

## О проекте
Учебный проект по решению задачи бинарной классификации (медицинская диагностика — предсказание наличия/отсутствия диагноза по набору клинических признаков).

Цель: построить модель логистической регрессии, оценить её качество и сравнить две реализации — через библиотеку `statsmodels` (максимальное правдоподобие) и «с нуля» через градиентный спуск.

## Данные
Датасет с клиническими показателями пациентов. Целевая переменная — бинарный признак диагноза.
Пропуски заполнены медианой, признаки стандартизированы (`StandardScaler`).

## Использованные методы и технологии
- **Язык:** Python
- **Библиотеки:** pandas, numpy, scikit-learn, statsmodels, matplotlib, seaborn
- **Методы:** логистическая регрессия (MLE), отбор признаков через хи-квадрат, ROC-анализ, подбор порога отсечения по F1, confusion matrix
- **Реализация «с нуля»:** сигмоида, логарифм правдоподобия, градиентный спуск

## Что сделано
- Обработка пропусков и стандартизация признаков
- Отбор значимых признаков (хи-квадрат)
- Разделение на train / validation / test со стратификацией
- Подбор оптимального порога отсечения на валидации по F1
- Оценка качества: accuracy, ROC-AUC, precision, recall, F1, confusion matrix
- Сравнение моделей MLE и SSR-минимизации
